# Blazly

Blazly is a marketing workspace. Fifteen specialist agents handle SEO, content, local search, AI visibility, and publishing. Each project is one brand or client website, and the agents work from that project's brand profile and connected data.

Sign-up requires a business-domain email. Personal addresses such as Gmail, Outlook, Yahoo, and iCloud are not accepted.

## How it works

Create a project with a name, website, and brand knowledge. Every chat, agent, integration, and schedule belongs to that project.

**Manual mode.** You pick one agent. It handles the first message, then the chat returns to normal conversation. You can run the same agent again from the chip or the + menu. Only one agent is active at a time.

**AI mode.** You describe the outcome in plain language. Blazly plans the agents it needs, runs them one after another, shows each result, and finishes with a summary and the credits used. It does not stop to ask which agent to use next.

Credits are spent only when an agent or chat actually runs. Unused plan credits roll over. Paid users who reach zero see a top-up popup.

## Also included

**Integrations, per project.** WordPress, Webflow, a custom webhook, Google Search Console, and GA4. Agents use them to publish and to read real search and traffic data.

**Scheduling, paid plans.** One-off tasks up to 30 days ahead, plus daily, weekly, and monthly recurrence. A scheduled task can chain up to 4 agents. Active schedule limits are 20 on Pro, 100 on Business, and 300 on Agency.

**Teams.** The owner pays and holds the credits. Seats are 3 on Business and 10 on Agency, not counting the owner.

**Referrals.** When someone you invite buys a paid plan, you receive 250 credits. Signing up alone does not pay the reward.

**Projects.** Each one has a website, brand knowledge, and logo. Shared projects let teammates work in the same brand.
